How I work

Research and engineering, in one loop.

1 · FrameWrite down the behaviour in question and what counts as evidence.
2 · ControlAdd null and alternative conditions so the result can’t hide a confound.
3 · BuildCode the harness to be reproducible: caching, checkpoints, tests.
4 · MeasureScore observable output and state the limits.
5 · ReportSay what to fix before scaling.

    ResearchAI/ML

    Agent compliance evaluation framework

    Problem
    Measure the gap between what an agent says it will do and what it actually does, without an LLM judge.
    My contribution
    Built independently: the two-stage elicitation protocol, original metrics, and a reproducible multi-model harness.
    Outcome
    216 test cases; 42–68% compliance gaps measured; 175 pytest tests.
    Source ↗
    Research

    Oversight-injection benchmark

    Problem
    Does a system-level oversight message injected mid-conversation change how an LLM refuses, complies or violates policy?
    My contribution
    Designed and ran the controlled multi-turn experiments (4 conditions × 15 scenarios, Qwen3 pilots) and scored observable output.
    Outcome
    Refusal rose 66.7 pp (turn 2) and 76.7–80.0 pp (turn 6); the null control reproduced the shifts, so a control fix is needed before scaling.
    No public link yet
    ResearchAI/ML

    Does reasoning help?

    Problem
    Does chain-of-thought improve LLM sentiment classification on financial text?
    My contribution
    Benchmarked five prompting strategies on 300 class-balanced samples; investigated and addressed a neutral-class bias in anchor prompting.
    Outcome
    89.67% with chain-of-thought vs 62% zero-shot (+27.67 pp) on this dataset.
