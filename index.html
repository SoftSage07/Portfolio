Agentic Prompting Research

Built an agentic evaluation framework benchmarking 5 LLM prompting strategies on 300 labeled financial sentences. Improved sentiment classification accuracy from 62% to 89.67% using Chain-of-Thought prompting — a +27% gain. Identified neutral bias and refined using anchor prompting with automated, reproducible pipelines.
